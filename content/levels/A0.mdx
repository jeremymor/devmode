## The Brief

Learn the tool every developer uses every day. Git tracks changes to your code, lets you collaborate with others, and saves you when things go wrong. You'll simulate a multi-person project using branches and pull requests — the same workflow used at every tech company.

Start by initializing a repo and making commits. Then branch out, make changes in parallel, and learn to merge them back together — including handling conflicts when two people edit the same thing.
