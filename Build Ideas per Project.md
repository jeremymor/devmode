# Track C: Security & Compliance

---

## C1: Vulnerable App — Build It Broken on Purpose

1. **Vulnerable online store** — SQL injection in search, XSS in reviews, CSRF on checkout
2. **Insecure social network** — stored XSS in profiles, IDOR on viewing other users' messages
3. **Broken banking app** — SQL injection in transfers, missing auth on API endpoints
4. **Vulnerable blog platform** — XSS in comments, CSRF on post deletion, path traversal in file uploads
5. **Insecure voting app** — vote manipulation via CSRF, SQL injection in results, missing rate limiting
6. **Broken file sharing app** — directory traversal, unrestricted file upload (upload a .php file), no auth on downloads
7. **Insecure API** — no authentication, mass assignment, SQL injection in query params
8. **Vulnerable wiki** — stored XSS, privilege escalation, insecure direct object references
9. **Broken password manager** — passwords stored in plaintext, XSS in notes field, session fixation
10. **Insecure chat app** — message injection, session hijacking, no HTTPS, cleartext credentials

---

## C2: Fix It — Harden Your Vulnerable App

1. **Harden your C1 online store** — parameterized queries, CSP headers, CSRF tokens, input validation
2. **Secure your social network** — output encoding, authorization checks, secure session management
3. **Fix your banking app** — prepared statements, middleware auth, rate limiting, audit logging
4. **Lock down your blog** — sanitize HTML, SameSite cookies, secure file upload validation
5. **Secure your voting app** — CSRF protection, input validation, rate limiting, result integrity checks
6. **Fix your file sharing app** — restrict upload types, sanitize filenames, add authentication
